# Contribution Policy

This repository is a single-author interview evaluation artifact, not an open-source collaboration project.

- Unsolicited code, design, documentation, or feature pull requests are not accepted and will not be merged.
- Opening a pull request does not grant the submitter any right to the proprietary portions of this repository and does not transfer ownership to the repository owner.
- Do not submit confidential employer information, personal data, copied interview solutions, or third-party material without documented permission.
- Security concerns should be reported privately to the repository owner through the GitHub profile. Do not post secrets or student information in a public issue.

If this project later accepts contributions, it will first adopt a separate written contribution agreement or DCO policy. Until then, the canonical history remains single-author.
